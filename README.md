# Aria: AI Girlfriend Companion & Assistant 💖

A realistic and anime AI Girlfriend Android application with live voice conversation, real-time lip-sync mouth animation, screen share assistant, and smart device actions (WhatsApp, Instagram, Phone calls, and Game launching).

---

## 📲 How to Download APK on GitHub (APK Download Kaise Karein)

Jab aap is repository ko GitHub par upload ya push karte hain:

### Method 1: Direct Download from "Releases" (Sabse Aasan)
1. Apne GitHub repository ke main page par jaaiye.
2. Right side me **Releases** section dikhega (ya page ke upar *Releases* tab par click karein).
3. **v1.0.0** ke andar **`Aria-AI-Girlfriend-v1.0.apk`** par click karein.
4. APK turant phone me download ho jayegi!

### Method 2: Download from "Actions" Tab
1. GitHub repository ke top menu me **Actions** tab par click karein.
2. Sabse upar wale **"Build & Release APK"** workflow run par click karein.
3. Page ke sabse niche scroll karein, wahan **Artifacts** me **`Aria-AI-Girlfriend-APK`** dikhega.
4. Click karke download karein!

## ✨ Features

- **🎙️ Live Anime Girlfriend Voice Screen**:
  - Live animated anime girlfriend character with natural breathing and body swaying.
  - **Realistic Lip-Sync Talking Mouth**: Jab girlfriend bolti hai, to real-time me uske lips aur mouth voice ke sath hilte hain!
  - Giant pulsing mic button for speech-to-text.
- **📱 Real Device Actions**:
  - *"Open WhatsApp"*, *"Send WhatsApp message to Rahul: Hello"*
  - *"Open Instagram"*, *"Post story on Instagram"*
  - *"Open Free Fire"*, *"Open BGMI"*, *"Open Subway Surfers"* (Koi bhi game bolkar launch karein)
  - *"Call Mom"*, *"Set alarm for 7 AM"*
- **🔴 Screen Share On / Off**:
  - 1-tap screen share toggle button with live girlfriend audio advice.
- **🎮 Game Coach Mode**:
  - Live pro coaching tips for BGMI, Free Fire, Call of Duty, Minecraft, Subway Surfers.
- **⚙️ Voice & Persona Customization**:
  - Voice pitch and speed sliders, 5 voice presets (*Sweet & Cute*, *Romantic*, *Playful*, *Calm*, *Tsundere*).
